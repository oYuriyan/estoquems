O Problema

6 dores que impediam
a operação de escalar.

Processos manuais, planilhas e comunicação informal geravam conflitos, retrabalho e atrasos que impactavam diretamente o atendimento ao cliente.

1

Reservas Conflitantes

Dois vendedores reservam o mesmo equipamento — retrabalho, atrasos na entrega, insatisfação do cliente.

2

Falta de Visibilidade em Tempo Real

Ninguém sabe o que está disponível — vendedores consultam manualmente ou ligam para o estoque.

3

Processos 100% Manuais

Propostas e reservas geridas em planilhas e e-mails — perda de dados, zero auditoria.

4

Sistemas Desconectados

O GLPI não reflete reservas feitas externamente — divergência de inventário, informação duplicada.

5

Sem Mobilidade para Vendedores Externos

Sem acesso remoto ao catálogo — dependência total de acesso presencial ou comunicação por telefone.

6

Sem Controle de Acesso

Qualquer pessoa pode alterar dados críticos — risco de alterações indevidas, sem rastreabilidade.

A Solução

Cada dor, uma solução
com mecanismo técnico robusto.

🔒

Lock Pessimista

Dor: Reservas conflitantes

SELECT ... FOR UPDATE garante integridade atômica no PostgreSQL.

⚡

WebSockets

Dor: Falta de visibilidade

Broadcast de eventos RESERVED/CANCELED atualiza todos os vendedores em tempo real.

📋

Propostas Digitais

Dor: Processos manuais

Fluxo completo: DRAFT → RESERVED → WON/CANCELED com PDF e WhatsApp.

🔗

Integração GLPI

Dor: Sistemas desconectados

Webhooks bidirecionais via n8n sincronizam reservas automaticamente com o GLPI.

📱

PWA Offline

Dor: Sem mobilidade

Service Worker + Cache API permitem acesso ao catálogo em qualquer dispositivo.

🛡️

RBAC + JWT

Dor: Sem controle de acesso

Papéis ADMIN/SALES com tokens JWT, bcrypt e auditoria completa.

Funcionalidades

Tudo que o time
precisa, em uma tela.

📦

Catálogo em Tempo Real

Agrupamento inteligente por modelo e specs. Busca full-text, filtros compostos, paginação infinita. WebSocket garante atualização instantânea para todos os vendedores conectados.

📝

Sistema de Propostas

Múltiplas propostas simultâneas, seleção de quantidade limitada pelo estoque, reserva atômica com lock pessimista. Exportação em PDF profissional e compartilhamento via WhatsApp.

🔒

Lock Pessimista

O mecanismo mais crítico: SELECT FOR UPDATE no PostgreSQL impede que dois vendedores reservem o mesmo equipamento. Testado com testes de race condition automatizados.

🔗

Integração GLPI via n8n

Workflows visuais de automação: reservas e cancelamentos são espelhados no GLPI em tempo real via webhooks. Se a integração falha, toda a transação é revertida (rollback).

📱

PWA + Modo Escuro

Instalável em celulares e desktops com suporte offline. Tema escuro/claro persistido com prevenção de FOUC. Interface responsiva do desktop ao mobile.

👥

Painel Admin + RBAC

Gestão completa de usuários com papéis ADMIN e SALES. Autenticação JWT com bcrypt, tokens com expiração de 8 horas, proteção contra brute-force.

Segurança

4 camadas de proteção,
do TLS ao banco de dados.

Camada 1

🌐 Rede

  • SSL/TLS com certificado
  • Portas internas não expostas
  • n8n acessível apenas via SSH tunnel
Camada 2

🛡️ Nginx

  • Rate Limiting: 5 req/min (auth)
  • Rate Limiting: 120 req/min (API)
  • Security Headers (CSP, HSTS, etc.)
  • Gzip + server_tokens off
Camada 3

⚙️ Aplicação

  • JWT com expiração
  • bcrypt para senhas
  • RBAC (ADMIN / SALES)
  • CORS restrito + Pydantic
Camada 4

🗄️ Banco de Dados

  • Lock pessimista (integridade)
  • Credenciais via env vars
  • Porta 5432 não exposta
